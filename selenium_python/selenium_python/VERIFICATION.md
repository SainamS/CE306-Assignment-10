# บันทึกการตรวจสอบชุดแล็บ

ตรวจเมื่อ 23 ตุลาคม 2026 ก่อนจัด ZIP

## การตรวจเอกสารฉบับแก้ไข

- ปรับภาษาในใบงานและคู่มืออาจารย์ด้วย humanizer และแทนตารางเวลาด้วยรายการแล็บ
- ลบเวลากำกับกิจกรรม ส่วนเวลารอของเว็บใน Lab 3 ยังระบุไว้ตามเงื่อนไขการทดลอง
- ตรวจว่าคำสั่ง ตัวอย่างโค้ด ลิงก์ และรหัสช่องคำตอบในเอกสารตรงกับฉบับเดิม
- ไฟล์โปรแกรม เว็บจำลอง ข้อมูล CSV และไฟล์ติดตั้งตรงกับ ZIP ฉบับเดิมทุกไบต์
- ตรวจการแสดงผลและดาวน์โหลดคำตอบภาษาไทยจากช่องกรอกทั้ง 14 ช่องอีกครั้งแล้ว
- ผลทดสอบโปรแกรมด้านล่างเป็นผลจากการตรวจฉบับเดิม โปรแกรมไม่ได้เปลี่ยนในการแก้เอกสารครั้งนี้

## ผลการตรวจโปรแกรม

- ระบบที่ตรวจจริง: Windows, Python 3.12.14, Selenium 4.51.0
- Chrome แบบ headless และแบบมีหน้าต่าง: ครบ 18 กรณี ผลเป็นไปตามแผน
- Edge แบบ headless: ครบ 18 กรณี ผลเป็นไปตามแผน
- Preflight Chrome/Edge: PASS อย่างละ 1
- เมนู interactive: เลือก 1 แล้วออกด้วย 0 ได้ PASS 5 และปิด browser/server ได้
- ระบุ driver ที่ไม่มีอยู่: แจ้ง ENVIRONMENT ERROR และ exit code 1 ตามคาด
- ไม่มี traceback รบกวนจาก client disconnect หลังแก้ handler; unrelated server errors ยังแสดงได้
- ใบงานและคู่มือ: ตรวจภาพ render ภาษาไทยบน Chrome, ไม่มี horizontal overflow ที่ desktop และกว้าง 430px
- กรอกข้อมูล 14 ช่องในใบงานและดาวน์โหลดคำตอบ TXT: ภาษาไทย UTF-8 ครบทุกช่อง
- ตรวจ event ก่อนพิมพ์: ช่องคำตอบขยายตามข้อความ ไม่มีการส่งคำตอบออกเครือข่าย
- ยังไม่ได้ทดสอบ macOS/Linux หรือการติดตั้ง/รันแบบตัดอินเทอร์เน็ตในห้องผู้ใช้ ต้อง preflight ก่อนสอน

## ขอบเขตการรับรอง

ผลนี้ยืนยันว่าชุดแล็บรันได้ในสภาพแวดล้อมที่ระบุ ไม่ได้รับรอง browser/driver ทุกเวอร์ชัน
ยังไม่ได้ทดลองใช้กับชั้นเรียนจริง
ความล้มเหลวตามแผนมีสองกรณีเท่านั้น: L3 immediate_lookup และ L4 credits_4_buggy
หากพบ FAIL, ERROR หรือ XPASS ในห้องเรียน ให้ตรวจเพิ่มเติม
